ABSENSI DIGITAL — PERTEMUAN 9

1. Nyalakan Apache + MySQL di XAMPP.
2. Buat database MySQL: absensi_digital
3. Buka CMD di folder project.
4. Jika vendor tidak ada: composer install
5. Jalankan: php artisan migrate:fresh --seed
6. Jalankan: php artisan serve --host=0.0.0.0
7. Buka: http://127.0.0.1:8000/admin/login
